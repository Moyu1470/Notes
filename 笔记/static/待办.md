# 视差效果

![image.png](https://cdn.jsdelivr.net/gh/Moyu1470/Notes/img/20260303101140083.png)

````ad-tip
假使相机挂在角色身上 背后背景都挂载ParallaxMove脚本 越远的场景 parallaxSpeed参数值越接近1 这样和角色本身运动 跟随就越紧密 而近处物体 则是越近数值越低

相对角色本身 运动速度越快 越容易远离角色当前位置
````

# 地图无限滚动

![image.png](https://cdn.jsdelivr.net/gh/Moyu1470/Notes/img/20260303102309892.png)

````ad-tip
这种不太适合做成无限地图 如果地图过长可能会造成精度丢失 导致最终图像不对齐

做这种游戏 最好还是做成 角色原地不动 两张/或者超过（反正得超过需要的张数+1张 防止露馅）规则图片拼接  超过一定距离恢复原位

````
